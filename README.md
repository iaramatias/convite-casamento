# Convite de Casamento — E&A

Convite de casamento digital desenvolvido para visualização na web, com design responsivo e acesso rápido pelos convidados.

## 🌐 Acesso online
Você pode visualizar o convite diretamente pelo GitHub Pages:
`https://iaramatias.github.io/NOME-DO-REPOSITORIO/`

## ✨ Funcionalidades / Destaques
- Layout responsivo (funciona no telemóvel e no computador)
- Informações do evento e confirmação de presença / mapa (se aplicável)
- Animações e estilos personalizados

## 🛠️ Tecnologias utilizadas
- HTML5
- CSS3
- JavaScript *(remova se não tiver usado JS)*

## 📁 Estrutura de pastas
- `index.html` — Página principal do convite
- `css/` ou `assets/` — Estilos, fontes e imagens
